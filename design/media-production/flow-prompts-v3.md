## Tool + settings
- Google Flow > Image. Model: Nano Banana 2.1. If a result looks plastic or fake, rerun that prompt on Nano Banana Pro.
- Portrait aspect (closest to 4:5). 4 outputs per prompt. Upscale the winner to 2K. Claude crops to 4:5.
- Fixes (remove a logo, darken the bottom, fix hands): ChatGPT Images 2.5, upload the image and ask for that one change.
- Save every pick to design/media-production/incoming/ named exactly like the file column.

## Consistency trick (the only reference image you use)
1. Generate band-shows.jpg first, text only, no references. Pick the best one.
2. For every other AI image, upload THAT image as the single reference and add the style line below.
Style line: "Match the photographic look of the reference image only (color grade, film grain, lighting mood). Do not copy its subject or layout."
